# Appendix: code-level specification for 0.6

Companion to `0.6-native-v3.md`. Where the plan gives contracts, this gives the concrete code,
file contents and algorithms. Implementation follows this text; deviations are recorded here first.

## A. Paths and the state-directory seam (`paths.py`, new)

Every host-side path is derived from one function so tests can redirect all state with one
environment variable and never touch `~/.agy-sandbox`.

```python
STATE_DIR_ENV = "AGY_SANDBOX_STATE_DIR"

def state_dir() -> Path:                      # $AGY_SANDBOX_STATE_DIR or ~/.agy-sandbox
def plan_path(sandbox: str) -> Path:          # state/sandboxes/<sandbox>/plan.json
def workload_dir(sandbox: str) -> Path:       # state/kits/<sandbox>/workload
def recreate_staging(sandbox: str, stamp: str) -> Path:   # state/recreate/<sandbox>/<stamp>
def host_browser_dir(sandbox: str) -> Path:   # state/host-browser/<sandbox>
```

`constants.STATE_DIR`, `HOST_BROWSER_STATE_DIR`, `UPGRADE_STAGING_DIR` are removed; `host_browser.py`
and `workload.py` call `paths`.

## B. `plan.json` schema (written by `compose.save_plan`)

```json
{
  "schema": 1,
  "agy_version": "0.6.0",
  "saved_at": "2026-11-06T12:00:00Z",
  "name": "agy-sandbox-demo",
  "workspace": "/Users/me/code/demo",
  "clone": false,
  "auth_mode": "sandbox-local",
  "workload": {"dir": "/Users/me/.agy-sandbox/kits/agy-sandbox-demo/workload", "fingerprint": "sha256:..."},
  "mixins": [{"name": "claude", "source": "/.../kits/claude", "bundled": true}],
  "kit_args": ["chrome-host.host_port=9222"],
  "env": ["ENVIRONMENT=development"],
  "ports": ["3000:3000"]
}
```

Rules:

- `fingerprint` = sha256 over the bytes of `workload.yaml` + `\0` + `workload.dockerfile` as written.
- `load_plan`: missing file → `None`; `schema > 1` → `ConfigError("sandbox plan was written by a newer agy-sandbox", hint="upgrade agy-sandbox")`; malformed JSON → `ConfigError` naming the path.
- `save_plan` writes atomically (temp file + `os.replace`). `delete_plan` removes the directory.
- `SandboxPlan.to_dict()` / `SandboxPlan.from_dict()` are the only serialisation code; `workload` becomes a nested `WorkloadRef(dir, fingerprint)` dataclass.

## C. Drift algorithm (`upgrade.diff`)

```python
def diff(saved: SandboxPlan, wanted: SandboxPlan) -> Drift:
    saved_sources = {m.source for m in saved.mixins}
    wanted_sources = {m.source for m in wanted.mixins}
    added   = tuple(m for m in wanted.mixins if m.source not in saved_sources)      # wanted order
    removed = tuple(m.name for m in saved.mixins if m.source not in wanted_sources)
    common  = {m.name for m in wanted.mixins if m.source in saved_sources}
    kit_args_changed = tuple(sorted(
        kit for kit in common
        if _args_for(saved.kit_args, kit) != _args_for(wanted.kit_args, kit)))
    return Drift(
        added=added, removed=removed, kit_args_changed=kit_args_changed,
        workload_changed=saved.workload.fingerprint != wanted.workload.fingerprint,
        clone_changed=saved.clone != wanted.clone,
        auth_mode_changed=saved.auth_mode != wanted.auth_mode,
    )

def _args_for(kit_args, kit) -> frozenset[str]:   # entries "kit.name=value" for that kit; unscoped "name=value" apply to all
```

- `Drift.in_place` is `not (removed or kit_args_changed or workload_changed or clone_changed)`.
- `Drift.reasons()` renders one line per blocker, e.g. `kit removed: chrome-devtools`,
  `kit arguments changed: agy-credentials`, `workload changed (Dockerfile.agy, build_args or setup_scripts)`,
  `clone mode changed (fixed at creation; use up --rebuild)`.
- Env and ports are never drift: `upgrade` always re-applies them.
- `upgrade` passes to `kit_add` only the arguments scoped to that kit plus unscoped ones.
- `auth_mode_changed` alone is informational: its effect is already in `added`/`removed`.

D.1 JSON normalisation:

```python
def _parse_json(text: str) -> Any:        # first '{' or '[' onward; anything before it is echoed via console.info
def _items(doc: Any, key: str) -> list[dict]:
    if isinstance(doc, list): return doc
    if isinstance(doc, dict): return list(doc.get(key) or [])
    raise SandboxError(...)
```

D.2 `inspect` mapping (tolerant of 0.46 camel/plain and 0.48+ snake_case; `raw` kept):

| `SandboxInfo` field | keys tried in order |
| :-- | :-- |
| `name` | `name` |
| `state` | `state`, `status` |
| `kits` | `kits`, `kit_refs`, `mixins` (strings or dicts with `ref`/`source`) |
| `workspace` | `workspace`, `workspace_path`, `workdir` |
| `clone` | truthy `source_repo_dir`, `clone`, `cloned` |

D.3 Errors: every non-interactive call goes through `_run`, which raises
`SandboxError(message, command=argv, returncode=rc, stderr=last 20 lines)` with the message
`'sbx <verb>' failed (exit <rc>)` and the stderr tail as the hint when non-empty.

## E. Kit descriptors (full text)

Translation rules applied to every current v2 kit:

- R1 `permissions.network.allow` → `network-policy@1.config.runtime.allow`, same entries, drop apt-mirror hosts (DHI base uses `deb.debian.org`, `dhi.io`; apt hooks are dropped).
- R2 `environment.variables` → `args: {NAME: {default: "...", env: NAME}}`.
- R3 `setup.install[]` / `setup.startup[]` → `lifecycle@1.config.install[]` / `startup[]`; `command` string stays a string, argv list stays a list; add `env: [...]` listing every `$VAR` the script reads other than the baseline; `user` kept; `background: true` kept.
- R4 Every `${{ kit.args.auth_mode }}` branch becomes a check of `SBX_CRED_<SERVICE>_MODE` (declared in `env:`), because credential kits are attached only in proxy-managed mode.
- R5 `credentials:` entries move to the `*-credentials` kit as `credential@1` with `phase: runtime`; `credentialFile.template` (a JSON string) becomes `credentialFile.structure` (a map).
- R6 `volumes:` → one `volume@1` entry per path.
- R7 `agentInstructions.content` → `agent-context@1.config.content`.

### E.5 `codex`, `codex-credentials`, `opencode`, `opencode-credentials`

Mechanical translation of the current specs with R1–R7. Specific deltas:

- `codex`: `FROM docker.io/sbx/codex-mixin:latest`; the install hook that writes `config.toml` and `auth.json` branches on `SBX_CRED_OPENAI_MODE` only (`oauth` → bearer config, `apikey` → `OPENAI_API_KEY: proxy-managed`, otherwise remove `auth.json`); `env: [SBX_CRED_OPENAI_MODE]`.
- `codex-credentials`: `openai` apiKey (inject `api.openai.com` `Authorization: Bearer %s`) + oauth (tokenEndpoint `auth.openai.com` `/oauth/token`, resourceHosts `chatgpt.com`, `api.openai.com`, sentinels `oai-oat01-proxy-managed` / `oai-ort01-proxy-managed`, no credentialFile: the kit's install hook writes auth.json from the mode).
- `opencode`: `FROM docker.io/sbx/opencode-mixin:latest`; MCP hook unchanged; the Copilot seed hook keeps its logic, gated on `SBX_CRED_GITHUB_MODE` and `GH_TOKEN` declared in `env:`.
- `opencode-credentials`: apiKeys for `groq`, `openrouter`, `anthropic`, `openai`, `google`, `xai`, and `github` (`GH_TOKEN`, not proxyManaged, Bearer on `api.github.com`/`api.githubcopilot.com`, Basic on `github.com`), with every inject domain in its network policy.

### E.7 `chrome-host`

```dockerfile
# kits/chrome-host/chrome-host.dockerfile
```

Note: `COPY --chown` on scratch creates `/home` and `/home/agent` owned by 1000, which the spec forbids

## F. `docker/Dockerfile.default` (full)

```dockerfile
# syntax=docker/dockerfile:1
# Default agy-sandbox workload. Copy it to your project as Dockerfile.agy to customise
# (agy-sandbox init --dockerfile). ARG values come from build_args in agy.yaml.
ARG BASE_IMAGE=docker.io/sbx/shell-image:latest
FROM ${BASE_IMAGE}
USER root
ENV DEBIAN_FRONTEND=noninteractive

ARG PYTHON_VERSION=none
ARG NODE_VERSION=none
ARG RUST_VERSION=none
ARG MOJO_VERSION=none
ARG APT_PACKAGES=""

# Build toolchain and terminfo for modern terminals (kitty, alacritty, ghostty, wezterm).
RUN apt-get update && apt-get install -y --no-install-recommends \
      build-essential pkg-config libssl-dev ncurses-term ncurses-bin ${APT_PACKAGES} \
    && rm -rf /var/lib/apt/lists/*
RUN mkdir -p /lib/terminfo && for t in \
      https://raw.githubusercontent.com/kovidgoyal/kitty/master/terminfo/kitty.terminfo \
      https://raw.githubusercontent.com/alacritty/alacritty/master/extra/alacritty.info \
      https://raw.githubusercontent.com/ghostty-org/ghostty/main/terminfo/ghostty.terminfo \
      https://raw.githubusercontent.com/wezterm/wezterm/main/termwiz/data/wezterm.terminfo; do \
      curl -fsSL "$t" -o /tmp/t.info && tic -x -o /lib/terminfo /tmp/t.info; done && rm -f /tmp/t.info

ENV RUSTUP_HOME=/usr/local/rustup CARGO_HOME=/usr/local/cargo PIXI_HOME=/usr/local/pixi \
    PATH=/usr/local/cargo/bin:/usr/local/pixi/bin:$PATH

RUN if [ "${PYTHON_VERSION}" != "none" ]; then \
      uv python install ${PYTHON_VERSION} && \
      ln -sf "$(uv python find ${PYTHON_VERSION})" /usr/local/bin/python && \
      ln -sf "$(uv python find ${PYTHON_VERSION})" /usr/local/bin/python3; fi
RUN if [ "${NODE_VERSION}" != "none" ]; then \
      curl -fsSL https://deb.nodesource.com/setup_${NODE_VERSION}.x | bash - && \
      apt-get install -y nodejs && rm -rf /var/lib/apt/lists/*; fi
RUN if [ "${RUST_VERSION}" != "none" ]; then \
      curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --default-toolchain ${RUST_VERSION} --profile minimal && \
      chmod -R a+w /usr/local/cargo /usr/local/rustup; fi
RUN if [ "${MOJO_VERSION}" != "none" ]; then \
      curl -fsSL https://pixi.sh/install.sh | PIXI_HOME=/usr/local/pixi sh && chmod -R a+w /usr/local/pixi && \
      pixi global install --channel https://conda.modular.com/max-nightly --channel conda-forge mojo && \
      chmod -R a+w /usr/local/pixi; fi

USER agent
WORKDIR /home/agent
```

Policy: tests assert on recorded argv, returned dataclasses and files written under the isolated
state dir. Console assertions are limited to the presence of a user-facing hint (e.g. the `upgrade`

## I. sbx version gating

- `up`, `down`, `recreate`: any sbx with v3 support (≥ 0.45). `require()` only checks presence, daemon, login.
- `upgrade`: refuses below 0.48 with `UpgradeRefused("sbx 0.48 or newer is needed for in-place upgrades", hint="brew upgrade --cask sbx")`.
- JSON parsing is version-agnostic (D.1), so no branch on version elsewhere.
